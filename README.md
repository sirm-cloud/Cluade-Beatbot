# Cluade-Beatbot

A collection of data visualization projects and experiments.

## Projects

### Forex Visualizer

A real-time forex data visualization web application built with React, TypeScript, and the PrimeAPI.io WebSocket API.

**Location:** `forex-visualizer/`

**Features:**
- Real-time WebSocket streaming of forex prices
- Interactive charts for bid/ask price visualization
- Support for 18+ popular forex pairs
- Responsive dashboard with live price tickers
- Automatic reconnection and error handling

**Tech Stack:** React 19, TypeScript, Vite, Lightweight Charts

[View detailed documentation →](./forex-visualizer/README.md)
